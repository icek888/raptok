## 1. SaaS конкуренты (закрытые, платные)

### 1.1 OpusClip — opus.pro

| Параметр | Значение |
|----------|----------|
| URL | https://www.opus.pro |
| Цена | Free: 60 credits/мес, watermark / Starter: $15/мес / Pro: $29/мес |
| Функция | AI нарезает длинные видео на короткие TikTok клипы |
| Источник | Загрузка файла или YouTube URL |
| Субтитры | AI-генерация на 20+ языках, анимированные |
| Формат | 9:16, 1:1, 16:9 |
| Watermark | Free = да, Pro = нет |
| Особенность | Virality Score — оценивает потенциал клипа |
| Слабость | **Не работает с rezka.ag**, нет своего трека, нет редактора фрагментов |

**Наша разница:** RapTok берёт видео из rezka.ag + накладывает свой трек + редактор фрагментов вручную. OpusClip работает только с загруженными/YouTube и сам выбирает фрагменты (без редактора).

## 4. Ключевые выводы

### Что делает RapTok уникальным

1. **Единственный инструмент берёт фрагменты из реальных фильмов** (через rezka.ag) — все конкуренты используют AI-генерацию или stock footage
2. **Единственный с поддержкой rezka.ag** — огромный русскоязычный рынок
3. **Свой трек + лирика** — рэпер загружает свой бит и текст, а не AI генерирует
4. **Полный редактор** — можно заменить любой фрагмент, а не принимать что AI выдал
5. **Self-hosted** — можно запустить на своём сервере, нет зависимости от облака
6. **Цена** — $10-15/мес дешевле большинства конкурентов ($15-29)

### Слабые места конкурентов

| Конкурент | Главный минус |
|-----------|--------------|
| OpusClip | Нет своего трека, нет редактора фрагментов, дорогой |
| Revid.ai | AI-визуалы вместо реальных фильмов, нет своего трека |
| Capify | Только lyric video (текст на фоне), нет нарезки фильмов |
| Vizard | Дорогой, нет своего трека, нет редактора |
| FlexClip | Stock templates, не специализирован для рэпа |
| Open source | Все делают AI-генерацию, никто не нарезает фильмы |

### Рыночная ниша RapTok

```
                    AI-генерация          Нарезка из фильмов
                    ┌─────────────────┐   ┌─────────────────┐
  General purpose   │ Kapwing, Vizard │   │      EMPTY      │
                    │ OpusClip        │   │  ← RapTok here  │
                    ├─────────────────┤   ├─────────────────┤
  Для рэперов       │ Revid.ai        │   │  ← RapTok here  │
                    │ Capify          │   │  ← RapTok here  │
                    └─────────────────┘   └─────────────────┘
```

**RapTok занимает пустую нишу: нарезка из реальных фильмов + свой трек + для рэперов.**

## 5. Рекомендации для RapTok

### Что взять от конкурентов

| Фича | Откуда | Приоритет |
|------|--------|-----------|
| Virality Score | OpusClip | P2 (позже) |
| Auto-captions (AI транскрипция) | OpusClip, Capify | P2 |
| Beat-sync (нарезать по битам) | Revid.ai | P2 |
| Sound wave overlay | Revid.ai | P3 |
| Bulk генерация (5 вариаций) | OpusClip | P2 |
| Social media scheduler | OpusClip Pro | P3 |

### Что НЕ делать

| Фича | Почему нет |
|------|-----------|
| AI-генерация визуалов | Мы берём из фильмов — это наше преимущество |
| AI-генерация битов | Рэпер загружает свой трек — это суть продукта |
| Voice cloning | Сложно,_legal риски, не нужно для MVP |

### Pricing стратегия

| План | Цена | Что |
|------|------|-----|
| Free | $0 | 3 клипа/день, watermark, 720p |
| Pro | $12/мес | 30 клипов/день, без watermark, 1080p, все источники |
| Studio | $30/мес | Безлимит, bulk, API, кастомные шрифты, приоритетный рендер |

**Конкурентное преимущество по цене:** Pro $12 vs OpusClip $15-29, Vizard $29

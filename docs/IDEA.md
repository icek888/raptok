# RapTok — TikTok Content Maker for Rappers

## Идея одним абзацем

**RapTok** — веб-приложение для рэперов, которое автоматически создаёт TikTok-клипы из фильмов или видео под музыку. Вставляешь ссылку на фильм, загружаешь трек и текст песни — система нарезает рандомные красивые фрагменты (3-5 секунд), склеивает их в ролик 21-30 секунд, накладывает субтитры с лирикой и твой трек. На выходе — готовый TikTok-клип в вертикальном формате 1080×1920. Можно редактировать фрагменты, менять тайминги, настраивать стили субтитров.

---

## Как это работает (для пользователя)

### Шаг 1 — Загрузка
1. Вставляешь ссылку на видео (rezka.ag, YouTube, или прямой URL mp4/m3u8)
2. Загружаешь свой трек (mp3)
3. Вставляешь текст песни (лирика)

### Шаг 2 — Анализ
Система скачивает видео, определяет длительность, выбирает 5-10 случайных фрагментов по 3-5 секунд из разных частей фильма. Показывает превью каждого фрагмента.

### Шаг 3 — Редактор фрагментов
- Видишь список выбранных фрагментов с превью
- Любой можно заменить: выбрать другой таймфрейм из видео
- Можно добавить/удалить фрагменты
- Можно изменить длительность каждого (3-5 сек)
- Общая длительность: 21-30 секунд

### Шаг 4 — Редактор субтитров
- Текст песни автоматически разбивается на строки
- Каждая строка привязана к таймлайну (по 3-5 секунд)
- Можно редактировать тайминги каждой строки
- Можно менять текст строк
- Настроить стиль: шрифт, цвет, обводка, позиция (сверху/снизу/центр)

### Шаг 5 — Стили
- Шрифт субтитров (5-10 вариантов)
- Цвет текста и обводки
- Позиция субтитров
- Blur фон по краям (как в TikTok)
- Формат: 1080×1920 (вертикальный)

### Шаг 6 — Генерация
- Нажимаешь "Generate Clip"
- Система рендерит видео через ffmpeg
- Превью результата
- Скачивание MP4

## Источники видео

| Источник | Как работает |
|----------|-------------|
| **rezka.ag** | Парсинг m3u8 URL со страницы → скачивание через ffmpeg |
| **YouTube** | yt-dlp скачивает видео (до 1080p) |
| **Прямой URL** | mp4, m3u8, webm — ffmpeg напрямую |

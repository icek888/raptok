## Step 2: Lyrics — Word Preservation + Timeline UX

### Task 4: Fix Apply Lyrics dropping words (DTW backtrack bug)

**Objective:** When user has 43 words and whisper detected 35, Apply Lyrics should return ALL 43 words, not 34.

**Files:**
- Modify: `backend/services/forced_alignment.py:96-156` (_dtw_align function)

**Problem (H3 from code review):** DTW backtrack uses `cost[i-1][j] + 1 == cost[i][j]` which is wrong — the backtrack should compare the actual cost matrix values that led to `cost[i][j]`, not assume +1. This causes silent word drops.

**Fix:** Rewrite backtrack to check which predecessor was the minimum:
```python
def _dtw_align(user_words, user_norm, whisper_words, whisper_norm):
    n = len(user_words)
    m = len(whisper_words)
    if n == 0 or m == 0:
        return None
    if n > 300 or m > 500:
        return None

    INF = float('inf')
    # Use 3-direction DTW: diagonal (match), up (insert user word), left (skip whisper word)
    cost = [[INF] * (m + 1) for _ in range(n + 1)]
    back = [[None] * (m + 1) for _ in range(n + 1)]  # track path
    cost[0][0] = 0

    for i in range(1, n + 1):
        for j in range(1, m + 1):
            match_cost = 0 if user_norm[i-1] == whisper_norm[j-1] else 1
            diag = cost[i-1][j-1] + match_cost  # match/replace
            up = cost[i-1][j] + 1              # insert (user word, no whisper match)
            left = cost[i][j-1] + 1            # delete (skip whisper word)
            best = min(diag, up, left)
            cost[i][j] = best
            if best == diag:
                back[i][j] = 'diag'
            elif best == up:
                back[i][j] = 'up'
            else:
                back[i][j] = 'left'

    # Backtrack with explicit path — NO word drops
    pairs = []
    i, j = n, m
    while i > 0:
        direction = back[i][j]
        if direction == 'diag':
            pairs.append((i-1, j-1))
            i -= 1
            j -= 1
        elif direction == 'up':
            # User word with no whisper match — assign interpolated timing
            pairs.append((i-1, j))  # j stays, will interpolate timing
            i -= 1
        else:  # left
            j -= 1

    pairs.reverse()

    # Build result — ALL user words preserved
    result = []
    for u_idx, w_idx in pairs:
        if w_idx < m and w_idx >= 0:
            result.append(WordTiming(
                word=user_words[u_idx],
                start=round(whisper_words[w_idx]["start"], 3),
                end=round(whisper_words[w_idx]["end"], 3),
            ))
        else:
            # Interpolate timing for unmatched user words
            # Find neighbors
            prev_end = result[-1].end if result else 0
            next_start = whisper_words[w_idx]["start"] if w_idx < m else prev_end + 0.5
            mid = (prev_end + next_start) / 2
            result.append(WordTiming(
                word=user_words[u_idx],
                start=round(mid, 3),
                end=round(mid + 0.3, 3),
            ))
    return result
```

**Key change:** `back[][]` array tracks the actual path. Unmatched user words (direction='up') are STILL included with interpolated timing — they're never dropped.

### Task 8: TimelinePreview — word drag = SWAP positions (drag-to-reorder)

**Objective:** When user drags word X and drops it on word Y, they SWAP positions.
Other words stay in place. No shifting, no compression — just two words exchange
their start/end timing. This is drag-to-reorder (like reordering items in a list).

**Files:**
- Modify: `frontend/src/components/TimelinePreview.tsx:185-203` (word-move drag handler)
- Modify: `frontend/src/components/SubtitleEditor.tsx:378-407` (onWordTimingsChange callback)

**Implementation in TimelinePreview:**

Add drop-target tracking during drag:
```tsx
const [dragWordTimings, setDragWordTimings] = useState<WordTiming[] | null>(null);
const [dropTargetIdx, setDropTargetIdx] = useState(-1);  // word being hovered

// In drag handler (mousemove):
if (dragMode === 'word-move' && dragWordIdx >= 0) {
  // Track which word we're hovering over for visual feedback
  const hoverTime = xToTime(e.clientX);
  const hoverIdx = wordTimings.findIndex(w => hoverTime >= w.start && hoverTime <= w.end);
  setDropTargetIdx(hoverIdx >= 0 && hoverIdx !== dragWordIdx ? hoverIdx : -1);

  // Visually move the dragged word with cursor (local state only)
  const wordW = dragStartData.wordEnd - dragStartData.wordStart;
  let ns = Math.max(0, dragStartData.wordStart + deltaT);
  ns = Math.min(ns, duration - wordW);
  const updated = [...wordTimings];
  updated[dragWordIdx] = { ...updated[dragWordIdx], start: ns, end: ns + wordW };
  setDragWordTimings(updated);  // preview position, no parent update
}

// In handleUp (mouseup = commit):
const handleUp = () => {
  if (dragMode === 'word-move' && dragWordIdx >= 0 && dropTargetIdx >= 0) {
    // SWAP: exchange timing between dragged word and drop target
    const dragged = wordTimings[dragWordIdx];
    const target = wordTimings[dropTargetIdx];
    const updated = [...wordTimings];
    updated[dragWordIdx] = {
      ...dragged,
      start: target.start,
      end: target.end,
    };
    updated[dropTargetIdx] = {
      ...target,
      start: dragged.start,
      end: dragged.end,
    };
    onWordTimingsChange?.(updated);
  } else if (dragWordTimings) {
    // No drop target — just move the word to new position (free drag)
    onWordTimingsChange?.(dragWordTimings);
  }
  setDragWordTimings(null);
  setDropTargetIdx(-1);
  setDragging(false);
  setDragMode('none');
  setDragWordIdx(-1);
};

// Render: highlight drop target with dashed border
{visibleWords.map(({ w, i }) => {
  const isDropTarget = i === dropTargetIdx && dragging;
  return (
    <div
      ...
      className={... `${isDropTarget ? 'ring-2 ring-yellow-400/60 border-dashed' : ''}`}
    >
  );
})}
```
